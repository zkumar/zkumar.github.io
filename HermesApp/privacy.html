Privacy Policy

Hermes Google Connector · last updated 28 October 2026

Hermes Google Connector ("the tool") is a private software application operated by a single individual on their own computer, for the purpose of accessing that same individual's own Google account data. This policy explains what data the tool touches and where it goes.

1. No server, no third parties

The tool has no backend service, no hosted database, and no analytics. It is not a multi-tenant application. It communicates directly from the owner's machine to Google's APIs over HTTPS. No Google user data is transmitted to, stored on, or processed by any server operated by this project, and no data is sold, rented, or shared with any third party.

3. What is stored on disk

  • OAuth token — an access token and refresh token issued by Google, stored at ~/.hermes/google_token.json with owner-only file permissions. This is what allows the tool to act without re-prompting.
  • Derived summaries — digests and notes generated from the accessed data, stored in the owner's local files and, when the owner asks, in the owner's own private Notion workspace.
  • Logs — local job logs recording which commands ran and their status. They are not transmitted anywhere.

No data is retained on any remote infrastructure because none exists. Deleting the files above removes everything the tool has stored.

4. Usage by third-party AI models

To produce summaries, text from the accessed content is sent to the AI model provider configured by the owner in their own Hermes Agent installation. That provider processes the content solely to generate the summary and is bound by its own data-use terms. This is inherent to the tool's function: it summarizes the owner's own email, and summaries require the text. No Google data is used to train models by this project.

5. Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used only to provide the single-user functionality described above; it is not used for advertising, not used to determine creditworthiness, and not used to train generalized AI models.

6. Retention and deletion

Data persists on disk until the owner deletes it. To remove all access and stored credentials:

  1. Revoke the app at myaccount.google.com/permissions — this invalidates the refresh token immediately.
  2. Delete ~/.hermes/google_token.json and any generated digest files on the machine.
  3. Delete any pages the tool created in the owner's Notion workspace.

7. Security

Credential files are written with owner-only permissions and never leave the machine. All API traffic uses HTTPS. The owner is the sole operator and sole user, so there is no credential sharing between parties.

8. Children

The tool is not directed at children and is not available to anyone other than its owner.

9. Changes

If this policy changes, the "last updated" date above will change. Because the tool has exactly one user, the owner is also the person making any such change.
