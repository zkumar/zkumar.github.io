Hermes Google Connector

A private, single-user integration between a personal Hermes Agent installation and its owner's own Google account.

This is not a public product. It is a self-hosted personal automation tool operated by one individual for their own Google data. There is no sign-up, no third-party users, and no server that stores your data.

What it does

Hermes Google Connector authorizes a locally-run agent on the owner's own machine to read and organize the owner's Google Workspace content so it can be summarized and filed into the owner's private notes:

  • Reading Gmail messages to produce a daily digest of items worth the owner's attention
  • Listing Google Calendar events to prepare a daily schedule brief
  • Reading Google Docs and Sheets the owner already owns, to summarize them
  • Listing files in the owner's own Google Drive
  • Reading the owner's own YouTube channel data
  • Reading the owner's own Google Contacts
  • Creating documents in the owner's own Google Drive and writing to the owner's own spreadsheets when the owner explicitly asks for it

All processing happens on the owner's machine. Access tokens are stored in a local file with owner-only permissions (~/.hermes/google_token.json) and can be revoked at any time.

Who can use it

Exactly one person: the owner of the Google account that authorized it. The application is not distributed, not published to any store, and has no mechanism for onboarding additional users. It falls under Google's personal use exemption (fewer than 100 users), which is why it has not been submitted for OAuth verification.

Data handling

The tool does not run a backend service. It is not a multi-tenant application. No Google user data is transmitted to, stored on, or processed by any server operated by this project. See the privacy policy for specifics on what is stored and how to delete it.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, which immediately invalidates the stored refresh token. The local token file can also simply be deleted.
